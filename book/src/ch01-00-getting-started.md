# Getting started

Let's begin. There is a lot to learn, and it starts with three small steps:

- [installing `ceesafec`](./ch01-01-installation), the CeeSafe compiler, on macOS, Linux or Windows;
- [writing a program](./ch01-02-hello-world) that prints `Hello, world!`;
- [making a package](./ch01-03-hello-package), which is how every CeeSafe program larger than one file is kept, and
  using the commands you will use every day: `check`, `run`, `build` and `fmt`.

At the end of the chapter you will have a working compiler and a program of your own to change.
